KiteAudio web verification

Serve the repository root over HTTP and open this page from localhost, which counts as a secure context. Each playback button plays a quiet 440 Hz tone for three seconds, by the technique chosen.

Open the page as index.html?early=js or ?early=wasmJs, with &mode=Buffers if you like, to start an output before any click. The Play button for that platform then starts the same output again, as a click handler would.

To play on another output, press List outputs, then choose one. The names stay empty until the page has a media permission, which Ask for permission requests through the microphone; list again after granting it. Choose a longer run to unplug the output while it plays, then press Start again to see what a start after the loss does.
